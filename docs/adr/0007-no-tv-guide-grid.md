# No TV guide grid

Live TV is reached through Favourites, search and the sports hub, not through a channel-by-time guide grid like TiviMate's. The Viewer mostly watches Movies and Shows, a fast grid over 45k Channels is a large piece of work on a small stick, and the Provider's guide covers only 15% of Channels with generic entries such as "Live: NHL Hockey". Sports are found from Event channel names and Game schedules instead.
