# The Prefix table for the surveyed Provider (survey of 2026-10-24).
#
# Maps each Prefix (the code before " - " in a Listing's name) and each Category hint (a phrase in a
# Category's name) to Version attributes. Everything here is Likely: names can be wrong, and a
# Header read or Playback Confirms or corrects it.
#
# Lines are `key | attribute; attribute; ...`. Attributes:
#   language=xx         the main audio's language, as a BCP 47 tag (fr-CA is Québec French)
#   subtitles=xx,yy     subtitle languages; `mul` means many languages
#   subtitled           the language named so far is the subtitles', the audio is the original
#   quality=4K
#   hdr=HDR10 | hdr=DV  Dolby Vision wins over HDR10 when both are named
#   source=Name         the streaming service the Version was copied from
#   dolby-audio, cam, audio-description
#   sports-replay       kept out of the movie list
#   clutter             not watchable content: kept out of every list
#
# A Prefix with no attributes is known but says nothing (a collection label, say). Prefixes missing
# from the table are reported after each Sync; add them here rather than guessing in code.
#
# Category hints are matched in the Category's name after folding superscripts, accents and case
# (so "ᴰᴼᴸᴮʸ ᴬᵁᴰᴵᴼ" reads DOLBY AUDIO and "PELÍCULAS" reads PELICULAS), as whole words; a hyphen
# joins words, so SUBS doesn't match inside MULTI-SUBS.
# A hint's language replaces the Prefix's.
#
# Clutter names are regular expressions matched anywhere in a Listing's name.
