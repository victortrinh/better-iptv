# The Base table: the Prefix table's conventions that most Xtream Providers share, shipped with the
# app and the same for every Provider.
#
# It holds the plain language codes (`EN`, `FR`, `QC`), the `4K-xx` and `xx-4K` combos, the Source
# codes (`NF`, `D+`, `AMZ`), the Category hints, the Clutter patterns, the Tier tags, the Channel
# quality words, the country aliases and the genre words. What one Provider's names mean beyond these
# (its typos, `CD` for German, and its own codes, `IN-KD` or `TOP`) is that Provider's Provider table,
# never this file: a second Provider must not inherit them. Hand-written Provider tables live in
# cloud/provider-tables/, one file per Provider, named by the SHA-256 of its host in lowercase hex,
# in this same format.
#
# A Provider table merges into this one:
#   - a line for a key this table has (a Prefix, a Category hint, a Channel quality word, a country
#     alias, a genre word) replaces this table's line;
#   - a line with an empty rule (`A+ |`, or just `A+`) keeps the key known but saying nothing, which
#     is how a Provider switches a Base meaning off; an empty country alias or genre word drops it;
#   - its event time zone replaces this table's;
#   - every other line adds: Clutter names, live Clutter names, empty Event slots, Tier tags.
# There is no delete syntax.
#
# The cloud serves a Provider table's learned lines (what that Provider's file reads agreed on, ADR
# 0014) after its hand lines, under `[learned prefixes]`, which only a Provider table has. A learned
# line lays its attributes over this table's line for the Prefix, one by one (a learned `fr` keeps a
# line's `fr-CA`), and a hand line for the same Prefix wins over it. It names only what a file
# states: language, quality, hdr, dolby-audio, or `multi-audio`, which says the Prefix's files mostly
# carry several audio languages, so it names none and its Versions are Untagged.
#
# Maps each Prefix (the code before " - " in a Listing's name) and each Category hint (a phrase in a
# Category's name) to Version attributes. Everything here is Likely: names can be wrong, and a
# Header read or Playback Confirms or corrects it.
#
# Lines are `key | attribute; attribute; ...`. Attributes:
#   language=xx         the main audio's language, as a BCP 47 tag (fr-CA is Québec French)
#   subtitles=xx,yy     subtitle languages; `mul` means many languages
#   subtitled           the language named so far is the subtitles', the audio is the original
#   quality=4K
#   hdr=HDR10 | hdr=DV  Dolby Vision wins over HDR10 when both are named
#   source=Name         the streaming service the Version was copied from
#   dolby-audio, cam, audio-description
#   multi-audio         learned lines only: no language (see above)
#   sports-replay       kept out of the movie list
#   clutter             not watchable content: kept out of every list
#
# A Prefix with no attributes is known but says nothing (a collection label, say). Prefixes missing
# from both tables are reported to the cloud after each Sync (never shown to the Viewer), and the
# weekly "Unknown Prefixes" issue lists them; add them here when most Providers share them, else to
# the Provider's own table, rather than guessing in code.
#
# Category hints are matched in the Category's name after folding superscripts, accents and case
# (so "ᴰᴼᴸᴮʸ ᴬᵁᴰᴵᴼ" reads DOLBY AUDIO and "PELÍCULAS" reads PELICULAS), as whole words; a hyphen
# joins words, so SUBS doesn't match inside MULTI-SUBS.
# A hint's language replaces the Prefix's.
#
# Clutter names are regular expressions matched anywhere in a Listing's name. Live clutter names
# apply to live Listings only, so a film named "Radio" stays. Empty event slots are live Clutter
# too, and they also count towards a Category being an Event Category (most of its Listings are
# Event channels or empty slots), which the browser leaves out. Finished Event channels are also
# hidden by the start time in their name, in code (Channels.kt), since that depends on the hour.
#
# Tier tags are the package words before a colon at the start of a live Listing's name (`VIP: TNT
# SPORT 1 ᴴᴰ`, `TR VIP: BEIN SPORTS 1`), which say which Provider package a Channel variant comes
# from and nothing about the Channel. Channel quality words are the words a live Listing's name
# ends with (`HD`, `ᴴᴰ ʰᵉᵛᶜ`, `HD (SAT)`, `ᴴᴰ/ᴿᴬᵂ ⁶⁰ᶠᵖˢ`), taken off the end one after another, each
# read with its Unicode superscripts normalised and whatever its case; one marked `superscript`
# counts only as the Provider's superscript tag, so a show named with the word keeps it. They say the
# variant's quality: 4K (UHD), HD (HD, FHD, RAW, whose names don't tell 720 from 1080 lines) or SD,
# and `hevc`. Two live Listings are one Channel when their names match once the Tier tag and the
# quality words are gone; the country tag (`UK:`, `CA FR:`, two capitals before the colon) stays
# part of the Channel's identity.
#
# The event time zone is the zone the Provider writes Event channel times in (`(2026-10-29
# 18:00:30)`, `@ Oct 27 7:00 PM`) when the name states none; a zone the name states (`(GMT)`,
# `EEST`, `UK Sun 9 Feb 3:00pm`) wins. One line, a zone id (`America/Toronto`). It decides when an
# Event channel counts as finished, which Game it matches and what time its card shows.
#
# Country aliases are the codes before the bar at the start of a live Category's name (`AR| `,
# `EX YU| `) that aren't a country: the whole code, as `code | name`. Each gets its own card in the
# Channel browser, named as written here, after the countries. A code that is neither a country
# (ISO 3166, with `UK` read as GB) nor listed here keeps its Categories out of the browser.
#
# Genre categories order a country's Categories in the Channel browser: a Category whose name has
# one of these words (matched as Category hints are) comes first, in the order its genre first
# appears here, as `word | genre`; the rest are the Provider's service buckets (`AT&T`, `PRIME`,
# `TUBI`, `PEACOCK`, `NETFLIX ON AIR`), which follow by Channel count. A name with words of two
# genres goes with the earlier genre.
#
# The Kids genre's words also make the Kids catalog (CONTEXT.md): a Title any of whose Listings sits
# in a Category with one of them (`EN - KIDS`, `FR - DESSINS ANIMÉS`) is in a Kids profile's library,
# and so is a Channel of a live Category with one; nothing is hidden from the other profiles by it.
# A Provider table adds a Kids word with `word | Kids` and empties one with `word |`. ANIMEE stays
# out: French panels file teen anime there.

# Radio stations filed with TV ("UK: BBC RADIO CUMBRIA", "T2: GRUNN FM"), but not TV named after
# a radio ("ICI RADIO-CANADA TÉLÉ", "RADIO BREMEN TV", "T2: REGIO FM TV"). Android's regex engine
# has no (?U) flag, so word edges are spelled out to count É as a letter.
